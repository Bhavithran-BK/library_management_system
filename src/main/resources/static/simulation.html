Hashed Shard Key Configuration

• library_db.books: { "bookId": "hashed" }
• library_db.members: { "memberId": "hashed" }
Hotspot Prevention: Because our system generates monotonically increasing 64-bit accession IDs (Snowflake timestamp prefix), a range-based shard key would route 100% of write traffic to the latest shard. Hashed sharding distributes inserts uniformly across both shard replica sets.
