🤝 Application Router & MongoDB Storage Architecture

Layer 7: Application Consistent Hashing Router

Routes catalogue cache keys, read requests, and microservice tasks across logical nodes with minimal key churn upon scaling.

Layer 4: MongoDB Database Sharding (mongos)

Mongos router distributes BSON records across replica set shards based on hashed shard keys { bookId: 'hashed' } and { memberId: 'hashed' }.

Synergy: Application consistent hashing ensures predictable cache locality and low latency; MongoDB sharding provides horizontal persistence capacity, high availability, and transparent chunk rebalancing.
